  
# 🎵 Cozymusic — Все тот же мод для Яндекса без плюса на все ОС.

Кастомная сборка десктопного клиента Яндекс Музыки, снимающая ограничения подписки и добавляющая расширенный функционал для комфортного прослушивания.

## ❤️ Приемущества:
🔓 Свободный доступ: Прослушивание музыки без подписки «Плюс». Клиент полностью автономен от официальной версии

🎧 Максимальный звук: Доступ к трекам в высоком качестве (HQ) и скачивание в FLAC или MP3.

🚫 Чистый интерфейс: Вырезана встроенная реклама и трекеры аналитики.

‼️ Обход цензуры: зацензуренные треки заменяются на оригинальные версии благодаря системе плагинов.

📜 Полный функционал: Работают подкасты, синхронизированные тексты песен и интеграция с Discord.

⚙️ Кастомизация и контроль: Поддержка пользовательских шрифтов, встроенный режим разработчика и отключенные авто-обновления.


## 💀 Ограничения:
• Сервис работает только в [некоторых странах](https://m.yandex.ru/support/music/ru/access-and-account/where-available). При использовании VPN убедитесь, что выбрана геопозиция одной из доступных стран.
